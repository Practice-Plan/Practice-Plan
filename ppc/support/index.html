02FAQ

Startup
Double-clicking the exe shows no window?
That is tray mode — the default. Check the tray area (it may be folded behind ^). Use ppc -t for a console.
The UAC prompt appears every time?
v0.1.0 requests elevation on launch by design. During debugging use ppc -t or ppc -no-elevate.
"Port already in use / another instance running"?
ppc and ppc32 share port 9527 with mutual exclusion — by design. Run ppc -stop, then start the architecture you want.
Does closing the terminal kill PPC?
No. A global console-control handler keeps the background instance alive (v0.1.0+).
Connection
My app cannot connect to 127.0.0.1:9527 (0x10017)?
Confirm PPC is running (tray icon / ppc PING), that the client targets the right port (PPC_PORT), and that you connect via 127.0.0.1 — not localhost aliases with proxies.
Commands answer UNKNOWN_COMMAND?
Check the spelling, then compare against HELP. Very old PPC versions lack newer commands — upgrade to v0.1.0.
UI & DLL
Popups look different from before / 0x10011 or 0x10012?
The native UI needs ppc_ui.dll beside the exe, matching its architecture. Missing or mismatched → PPC silently falls back to the built-in Win32 stub. Fix the file pairing and restart.
Registration
REGISTER_APP returns 0x10005 (failed)?
Check the payload format — app_id|version|exe_path on one line, pipe-separated — and that your signature is valid for the build.
Do I still need AUTH?
No. Since v0.0.8 all commands are open. AUTH is optional identity — used only so APPLOG and log lines show your app instead of a guest.

04Troubleshooting

Four scenarios cover most real-world failures.

A · Won't start

  1. Look in the tray — it may already be running (single instance).
  2. ppc -stop, then ppc -t to watch startup output.
  3. If another PPC architecture holds the port, -stop clears it.
  4. Still failing → collect terminal output and email it.

B · Connection refused

  1. ppc PING — expect PONG.
  2. ppc -healthy — full health check.
  3. ppc -log 100 — look for bind errors or a custom PPC_PORT.

C · Popups degraded

  1. Confirm ppc_ui.dll sits beside the exe, matching its architecture.
  2. ppc -log 100 — a load-failure line names the exact reason.

D · Version mismatch (0x10019)

  1. ppc PPCVERSION — read the server version.
  2. Compare with your connector's supported range.
  3. Upgrade whichever side is behind.

06Versions

Current stable: v0.1.0 (2026-10-01).

Compatibility: apps written for v0.0.8+ run unmodified on v0.1.0 — the command interface stays backward-compatible.

Upgrading: portable — replace the files; MSI — rerun the installer. Your app database and logs carry over.

History: v0.0.6 → v0.0.7 → v0.0.8 → v0.0.9 → v0.1.0 — full timeline on the home page.
