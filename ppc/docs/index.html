01Quick start

From download to a running, verified server in five minutes.

1 · Install

Download v0.1.0 from the release section. Pick win64 for 64-bit Windows, win32 for 32-bit.

Portable: unzip and run. MSI: run the installer and follow the wizard.

Keep ppc_ui.dll next to the exe — a 32-bit exe needs the 32-bit DLL.

2 · First launch

Double-click the exe, accept the UAC prompt, and PPC settles into the system tray. Add -t to see the console instead.

3 · Verify

Three commands confirm the server is alive and healthy:

● ● ●
ppc PPCVERSION → PPC Version: 0.1.0
ppc PING → PONG
ppc -healthy → OK

4 · Stop

ppc -stop shuts down gracefully, or use Tray → Exit. Closing the console window never kills the background instance.

02Installation

Two distribution formats, one requirement.

Requirements

Windows x64 or x86. No runtime dependencies — PPC compiles to a self-contained native binary.

Directory layout

● ● ●
<ppc>/
├── ppc.exe # or ppc32.exe (x86)
├── ppc_ui.dll # C++ Win32 UI (must match exe arch)
├── dll_default/
│   └── dll_info.json
└── logs/ # created on first run, one file per session
!Arch pairing: a 32-bit exe cannot load a 64-bit DLL. When in doubt, use the matching release bundle — it ships the correct pair.

Portable (zip) — unzip anywhere, run directly. Ideal for USB tools and locked-down machines.

Setup (msi) — standard Windows installer with Start-menu integration. Best for long-term installs.

03Modes & tray

One binary, two faces — silent by default.

Tray mode (default): after launch, PPC hides in the system tray. Right-click for menu: Open, Log Viewer, Exit.

Terminal mode: ppc -t keeps a live console with session logs.

Single instance: ppc and ppc32 share port 9527 and are mutually exclusive — only one PPC ever runs.

Terminal-proof: a global SetConsoleCtrlHandler keeps the background instance alive when you close the console.

06App integration

Register your app once, then talk to the core.

1 · Connect

Open a TCP socket to 127.0.0.1:9527.

2 · Register

Send your identity in one line, pipe-separated:

● ● ●
REGISTER_APP
myapp|1.0.0|C:/Program Files/myapp.exe # app_id|version|exe_path

3 · Confirm init.json

On success PPC writes init.json next to itself. If versions mismatch later, delete it and re-register via -update.

● ● ●
{"ppc":"true","version":"1.0.0","app_id":"myapp"}

4 · Talk

Send any command, read the response, close at will. Minimal Rust client:

● ● ●
let mut s = TcpStream::connect("127.0.0.1:9527")?;
s.write_all(b"VERSION ALL\n")?;
let mut buf = [0u8; 2048];
let n = s.read(&mut buf)?;
println!("{}", String::from_utf8_lossy(&buf[..n]));
!C# apps can skip the plumbing entirely — the open-source APP_TOP client ships a protocol-compatible PpcConnector.

07Logs & diagnostics

Every session writes its own file: logs/ppc-YYYYMMDD-HHMMSS.log.

Tray → Open — the real-time viewer (200ms poll, 1000-line ring buffer).

CLI: ppc -log 100 prints the last 100 lines.

TCP: LOG 100 returns them programmatically.

Diagnostic triple: ECHO (connectivity) → STATUS (health) → LOG (what happened).

08Env & paths
