UI isolation

Thread-safe by construction

Four steps to integration

Any language that speaks TCP can join — the protocol is plain text over one connection.

Connect

Open a TCP connection to the local listener.

127.0.0.1:9527

Register your app

Announce identity — id, version and exe path, pipe-separated.

REGISTER_APP myapp|1.0.0|C:/path/app.exe

Confirm init.json

On success PPC writes an init.json next to your app — version mismatch? re-register with -update.

{"ppc":"true","version":"…","app_id":"…"}

Send commands

16 commands, stable since v0.0.8. Apps written for 0.0.8 run unmodified on 0.1.0.
